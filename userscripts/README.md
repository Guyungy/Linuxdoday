# Linux.do 顺序阅读助手

在 Chrome 的 Tampermonkey（油猴）中选择“添加新脚本”，用 `linuxdo-reader.user.js` 的全部内容替换编辑器内容并保存。打开已登录的 `https://linux.do/`，右上角会出现“Linux.do 顺序阅读”面板。

默认选择 200 条实时新话题，每条停留 20 秒并逐步滚动。点击“新一批”开始；“暂停”保留进度；“继续”从当前断点恢复。结束后可再次点击“新一批”。请保持运行标签可见，后台标签的浏览器计时和站点阅读统计可能受到限制。

脚本从 `/new` 页面实时分页选题，不读取本地抓取缓存。它只操作主题页面，不提交点赞、回复或阅读统计接口。主题很长时，设定的停留时间不代表已读完整主题。遇到登录页、页面加载失败或真人验证会暂停，手动处理后点击“继续”。

面板的进度表示脚本完成打开和停留的主题数；升级要求的实际计数以 [LINUX DO Connect](https://connect.linux.do/) 为准，不能保证每次打开都增加计数。
