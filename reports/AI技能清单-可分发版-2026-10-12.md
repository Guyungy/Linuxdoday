# AI 技能清单（可分发版）

> **用途**：培训课后发给学员的自选清单。按"要它解决什么"分八类，逐条给出 **名称 / 作用 / 使用方法 / 地址**。
> **来源**：linux.do 站内《Skill / MCP 推荐总表》（topic 2533306）与《SKILL 资源汇总》（topic 1781755）——社区众筹、每条带真实评价与推荐人。
> **两点提醒**：① 这些多数属于 Claude Code / MCP 生态，与豆包生态不完全通用，能不能用、怎么接需要实测；② **装任何第三方技能之前，先跑一遍安全扫描**——技能是在你的身份下执行的，装进来就等于把你能看到的范围（云盘资料、本机文件、账号凭据）交给它。

## 一、思考 / 推理

| 名称 | 作用 | 使用方法 | 地址 |
|---|---|---|---|
| Grill Me | 对方案连续追问、挑战假设，暴露设计漏洞 | 方案评审前先跑一遍，专门让它挑刺 | https://github.com/mattpocock/skills |
| Grill With Docs | 追问的同时对照需求 / 规约核验 | 有明确规格文档时比原版更稳 | https://github.com/mattpocock/skills |
| Sequential Thinking | 把复杂问题拆成分步推理，可中途修正回溯 | 复杂问题拆解；部分工具已内置该能力 | https://github.com/modelcontextprotocol/servers |

## 二、开发 / 编程

| 名称 | 作用 | 使用方法 | 地址 |
|---|---|---|---|
| Superpowers | 一整套"代理式编程"方法论 + 可组装技能框架 | 覆盖头脑风暴→spec→TDD→代码评审，按需取用 | https://github.com/obra/superpowers |
| OpenSpec | 规约驱动开发：先把大模块写成结构化 spec 再实现 | 大模块完整开发最稳，小改动不必 | https://github.com/Fission-AI/OpenSpec |
| Ponytail | 约束只改指定范围，避免误伤无关逻辑 | 改代码前先声明改动范围 | https://github.com/alonbaron/claude-skills |
| Exa Search | 高质量语义搜索 | 比让 AI 反复试各种请求靠谱 | https://mcp.exa.ai/mcp |

## 三、浏览器 / 自动化

| 名称 | 作用 | 使用方法 | 地址 |
|---|---|---|---|
| Playwright MCP | 页面操作、UI 测试、数据抓取 | 需要操作网页时的默认选择 | https://github.com/microsoft/playwright |
