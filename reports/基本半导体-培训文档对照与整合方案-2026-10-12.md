## 3. 五个你可能没注意到的点

**① 撞车要处理**
我上一轮交付了两份飞书文档（`培训执行方案`、`60 分钟课表与材料包`）。其中"60 分钟课表"与你这篇是**同一件事的两个版本**——两版课表并存会让对接方不知道以哪份为准。建议**下线我那份课表，只保留材料包部分**。

**② 真正的宝藏不是讲稿，是讲稿里那个技能**
`lot-progress-sync` 流片进度同步——Lot ID 匹配、前后进度滚动、**SHA256 指纹去重**、SCRAP 审计与报废视图。这是**"能跑"的证据**，比任何现场 demo 都硬。而且它在 `08·实战复盘` 里有完整来龙去脉（手工脏 Excel → 每日自动更新，"不改客户 Excel""只更新我要更新的字段"两条经验）。**这两条经验值得进讲稿**。

**③ 方法论同源，但口径要对齐**
讲稿里"课堂抓住五件事｜提炼自《如何写一个好的 skill》"，与我上一轮从 linux.do 挖出的 **帖子 1923706**（《如何写一个 skill 让你的效率加倍!》，2026-04-08，155 回复 / 15,034 浏览）是**同一篇母本**。

- 讲稿提炼：①描述写清触发场景 ②规则配可检验的问题 ③简单任务从小结构开始 ④同时测试调用与结果 ⑤从真实错误中更新规则
- 我挖到的原话纲领：**「结构服务于内容，激活优于存储，结构可复用，内容禁止预制」**

两者**不是同一条**。要么原帖有多个版本，要么是转述取舍。**建议核对一次**——因为讲稿的"完整参考"阅读表里带了 `1.1 单文件 / 2.1 薄壳 / 2.11 自动验证` 这类编号，像是有个"原文"在别处（你 10-10 17:09 建过一个同名空壳 wiki 节点 `FM7Xwd5WCiqJfdkt0Crcb8IinSe`，是空的）。

**④ 张漫玲的修改意见已经落地了**
10-10 16:42 的私聊意见是"删重复内容、重点讲价值和案例、**讲完工作伙伴之后再教大家怎么写技能**"。看现在的骨架——价值(0-10) → 案例(10-25) → 技能(25-45) → 工作伙伴(45-53)——**结构已按她意见改过**，可以放心。

**⑤ 你手上的资产链比讲稿值钱**
讲稿只是入口，背后还挂着一整套可直接复用的东西（见下节）。

## 5. 整合方案（推荐）

### 5.1 分工原则

```
┌──────────────────────────────┐     ┌──────────────────────────────┐
│  正片·现场 60 分钟            │     │  附件·课后自学包（新增）      │
│  《豆包工作价值与技能实操》    │ ──▶ │  《学员自学手册》             │
│  讲师讲稿，已有，不动          │     │  学员离线可用，本次要新建      │
└──────────────────────────────┘     └──────────────────────────────┘
        讲完就结束                        现场讲不完的全部下沉到这里
```

**核心原则：附件只写"现场没时间讲完、但学员回去一定会用到"的东西。不讲过的不要重复讲，讲过的不要重复写。**

### 5.2 附件（学员自学材料包）目录

| 层 | 名称 | 建议时长 | 内容 | 与讲稿的关系 |
|---|---|---|---|---|
| L0 | 上一场速查卡 | 5′ | 账号入口/客户端安装/快捷键（上一场已讲） | **改成速查卡**，不重写教程 |
| L1 | 概念速查 | 10′ | Agent / Skill / 工作伙伴 三者关系，一页表 | 讲稿 0–10′ 的浓缩版 |
| **L2** | **岗位练习卡（最厚）** | 按岗选读 | **直接搬讲稿第 4 章的 5 张卡**：财务 2027 预算检查 / 研发周报汇总 / 项目经理里程碑巡检 / 销售重点客户覆盖 / 流片进度对比 | **原样搬运 + 补"怎么自己做一张"** |
| L3 | 写 Skill 深入 | 1h+ | **不重写**，改为《如何写好一个 SKILL》原文导读 + 讲稿已给的阅读索引表 | **讲稿已覆盖，附件只做索引** |
| L4 | 红线与合规 | 10′ | 三条红线集中成一页：不承诺未接通系统 / 不替业务做审批判断 / 不把计划写成完成 | 讲稿散落在各段，**附件做集中汇总** |
| L5 | 模板库 | 随取 | ①SKILL.md 七件事骨架 ②三条可复制 Prompt（体验/追问/更新，讲稿原文抽出）③任务五要素模板 | **从讲稿抽取成可复制块** |
| L6 | 常见问题 20 问 | 随时 | 讲稿"常见问题与排查"6 条 → 扩到 20 条 | 讲稿 6 条 + 补 14 条 |
| L7 | 四周路线 | — | 第 1 周跑通 → 第 2 周复用 → 第 3 周写技能 → 第 4 周传同事 | 讲稿"课后延续"的展开 |

### 5.3 三条必须校准的口径（否则材料包会自相矛盾）

1. **不得写成"可随时查 ERP/CRM"** —— 讲稿明确"尚未完整接通，不承诺实时联查"，附件必须沿用同一口径。
2. **模板要标注"以当前客户端入口为准"** —— 讲稿反复强调"规则文本 ≠ 已安装成功的技能"，附件里的 SKILL.md 骨架不能暗示"复制粘贴就能用"。
3. **引用别人的素材要标来源** —— 讲稿里的"原版视频/原版界面"来自上一场（字节租户），附件引用时必须写清出处。
